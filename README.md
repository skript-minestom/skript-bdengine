# skript-bdengine
A skript-minestom addon allowing users to spawn and animate [bdengine](https://bdengine.app) models.
You can also find public models [here](https://block-display.com/).

## Features
- [x] Model Spawning
- [x] Model Animations
- [x] Animation Sounds
- [ ] Particles
- [ ] Hitbox (interaction entity)

## How can I import a model?
1. Export the model as a datapack
2. Unzip it
3. Go to data/.../function and copy that function folder
4. Upload the folder to skript-bdengine/functions and rename it to the model id you want

### You can find documentation and examples for the addon [here](https://smdocs.hapily.me/?addons=skript-bdengine)!
